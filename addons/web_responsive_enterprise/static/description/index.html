Web Responsive Enterprise

The Odoo 19 Enterprise look & app drawer — for Community Edition.

An upgrade-safe backend theme that brings the Enterprise purple brand, a full-screen app drawer (home menu), and modern responsive + accessible refinements to Odoo 19 Community — without touching Odoo core. Free & open source (LGPL-3).

Enterprise look

Purple brand navbar, accents and buttons, rounded cards & dialogs, soft shadows, a sticky control panel and refined notebook tabs — the polished Enterprise feel, in Community.

App drawer

A full-screen home menu: the apps grid button opens a search box and a grid of large app icons, with fuzzy search across every menu item. The navbar stays visible above it.

Fully responsive

Touch-friendly controls, no horizontal scrolling, edge-to-edge form sheets and full-width kanban cards on phones — works cleanly from 320px upwards.

Accessible & safe

Keyboard focus rings, reduced-motion support and WCAG-AA contrast. Built only on stable, public Odoo extension points, so it stays compatible across 19.0 point releases.

Installation

Install like any module: copy web_responsive_enterprise into your addons path, update the Apps list, and install. No configuration needed — hard-refresh your browser and the Enterprise look is applied. To uninstall, simply remove the app; Odoo core is untouched.
